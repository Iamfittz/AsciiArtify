
### 1. Create Kubernetes Cluster (k3d)

```bash
k3d cluster create asciiartify --port 8080:80@loadbalancer
```
### 2. Install ArgoCD
```bash
kubectl create namespace argocd
kubectl apply -n argocd -f https://raw.githubusercontent.com/argoproj/argo-cd/stable/manifests/install.yaml
```
### 3. Access ArgoCD UI
```bash
kubectl port-forward svc/argocd-server -n argocd 8081:443
```

go to https://localhost:8081

You have to click Advanced ->Proceed to localhost (unsafe)

### 4. Get admin pass

Login - admin

Password must be generated by the folloeing command.
```bash
kubectl -n argocd get secret argocd-initial-admin-secret \
  -o jsonpath="{.data.password}" | base64 -d && echo
```
